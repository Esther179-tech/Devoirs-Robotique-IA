# Devoir 3 — Bras robotique à plusieurs degrés de liberté

## 1. Objectif du projet
Construire et programmer un bras robotique capable d'effectuer des mouvements précis grâce à plusieurs servomoteurs.

## 2. Outils et composants utilisés
- Plateforme : Tinkercad Circuits
- Carte : Arduino Uno
- Servomoteurs : 2 
- Fils de connexion
- Environnement de programmation Arduino

## 3. Fonctionnement du projet
Les servomoteurs contrôlent les mouvements du bras robotique. Chaque servomoteur permet de contrôler un axe de mouvement. Le programme commande les angles de rotation pour placer le bras dans différentes positions.

## 4. Degrés de liberté
À compléter selon le nombre d'axes de mouvement réalisés dans le circuit.

## 5. Résultats obtenus
À compléter après la construction, la programmation et les tests du bras robotique.

## 6. Captures d'écran
Les captures du circuit Tinkercad, du code et des mouvements simulés seront ajoutées ici après les tests.
