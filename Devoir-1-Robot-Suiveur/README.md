# Devoir 1 — Robot suiveur de ligne

## 1. Objectif du projet
Programmer un robot virtuel pour qu'il suive automatiquement une ligne tracée au sol.

## 2. Outil utilisé
- Plateforme : VEXcode VR
- Terrain : Line Tracking
- Environnement : programmation par blocs

## 3. Fonctionnement du projet
Le robot utilise ses capteurs pour détecter la ligne au sol et ajuste ses mouvements afin de suivre son parcours.
