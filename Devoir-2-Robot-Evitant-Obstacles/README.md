# Devoir 2 — Robot évitant les obstacles

## 1. Objectif du projet
Programmer un robot virtuel pour qu'il détecte les obstacles et change automatiquement de trajectoire afin de les éviter.

## 2. Outils utilisés
- Plateforme : VEXcode VR
- Environnement : programmation par blocs
- Capteur : capteur de distance du robot virtuel
- Terrain : Obstacle Course, si disponible

## 3. Fonctionnement du projet
Le robot avance et mesure la distance qui le sépare de l'obstacle situé devant lui.

Lorsque la distance mesurée devient trop faible, le robot s'arrête, tourne pour changer de direction, puis continue d'avancer.

Si aucun obstacle n'est proche, il continue son déplacement.
